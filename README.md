# AI Football Analytics Dashboard

AI-powered football analytics dashboard built using Streamlit, Python, Machine Learning, and StatsBomb event data.

## Features
- Heatmaps
- Pass Maps
- Passing Networks
- Shot Maps
- Radar Charts
- Match Statistics
- Team Comparison
- AI Insights
- Post-Match AI Analysis

## Tech Stack
- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly

## Run Locally

```bash
pip install -r requirements.txt
streamlit run backend/app.py
