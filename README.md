# ⚽ AI Football Analytics Dashboard

AI-powered football analytics dashboard built using Python, Streamlit, Machine Learning, and StatsBomb open data.

## 🚀 Live Demo

https://ai-football-analytics-dashboard-appzsyrtcssdlmrpzuqj8af.streamlit.app/

---

## 📌 Features

* 🔥 Player Heatmaps
* 🎯 Pass Maps
* 🕸 Passing Networks
* ⚽ Shot Maps
* 📊 Match Statistics
* 👤 Player Statistics
* 📈 Radar Charts
* 🤖 AI Match Insights
* 🏆 Team Comparison
* 🧠 Post-Match AI Analysis

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/leosabarish18/AI-Football-Analytics-Dashboard.git
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
streamlit run backend/app.py
```
